# ระบบจัดการวัตถุดิบและขายหน้าร้าน (POS) ร้านบังเป้ ระยอง

PHP 8 + MySQL/MariaDB + Bootstrap 5 ใช้งานได้ทั้งบนคอมพิวเตอร์และโทรศัพท์

## ติดตั้งด้วย XAMPP

1. ติดตั้ง XAMPP (PHP 8.0 ขึ้นไป) แล้วเปิด Apache และ MySQL
2. คัดลอกโฟลเดอร์ `bangpe` ไปไว้ที่ `C:\xampp\htdocs\bangpe`
3. เปิด http://localhost/phpmyadmin เลือกแท็บ Import แล้วนำเข้าไฟล์ `database.sql`
   (ไฟล์จะสร้างฐานข้อมูล `bangpe_pos` พร้อมข้อมูลตัวอย่างให้เอง)
4. ถ้า MySQL ตั้งรหัสผ่านไว้ ให้แก้ใน `config/database.php`
5. เปิด http://localhost/bangpe

| ชื่อผู้ใช้ | รหัสผ่าน | สิทธิ์ |
|---|---|---|
| admin | admin123 | ผู้ดูแลระบบ ใช้ได้ทุกเมนู |
| cashier | cashier123 | แคชเชียร์ ขายหน้าร้าน ดูบิลและสต็อก |

เปลี่ยนรหัสผ่านที่หน้า "ผู้ใช้งาน" หลังติดตั้ง

**หมายเหตุ:** หน้าเว็บโหลด Bootstrap ฟอนต์ และไอคอนจากอินเทอร์เน็ต เครื่องที่ใช้ต้องต่อเน็ต

## เปิดดูบนโทรศัพท์ (ฟรี)

1. ให้โทรศัพท์กับคอมที่เปิด XAMPP ต่อ WiFi เดียวกัน
2. ดู IP ของคอม: เปิด Command Prompt พิมพ์ `ipconfig` ดูที่ IPv4 Address เช่น `192.168.1.5`
3. บนโทรศัพท์เปิด `http://192.168.1.5/bangpe`
4. ถ้าเข้าไม่ได้ ให้อนุญาต Apache ใน Windows Firewall

## หลักการทำงานที่ควรอธิบายได้ตอนสอบ

**ตัดสต็อกอัตโนมัติ:** แต่ละเมนูมีสูตร (`recipes`) บอกว่า 1 จานใช้วัตถุดิบอะไรเท่าไร เมื่อกดขาย
ระบบรวมวัตถุดิบที่ต้องใช้ทั้งบิล ล็อกแถวข้อมูล (`FOR UPDATE`) ตรวจว่าพอ แล้วบันทึกบิลกับตัดสต็อกใน
transaction เดียว ถ้ามีขั้นตอนไหนผิดพลาด ทุกอย่างจะถูกยกเลิก ข้อมูลจึงไม่ค้างครึ่ง ๆ กลาง ๆ

**ประวัติการเคลื่อนไหว:** ทุกครั้งที่จำนวนวัตถุดิบเปลี่ยน (รับเข้า ขาย เบิก ปรับยอด คืนจากยกเลิกบิล)
จะถูกบันทึกใน `stock_movements` พร้อมยอดคงเหลือหลังทำ ผู้ทำ และเวลา รายงานทั้งหมดดึงจากตารางนี้

**หน่วยซื้อกับหน่วยใช้:** สต็อกเก็บในหน่วยเล็กสุด (เช่น กรัม) ตอนรับเข้าเลือกกรอกเป็นหน่วยซื้อได้
(เช่น 2 กิโลกรัม) ระบบแปลงเป็น 2,000 กรัมให้

**ยกเลิกบิล:** คืนวัตถุดิบตามที่ตัดไปจริงตอนขาย (ไม่ใช้สูตรปัจจุบัน) เฉพาะ admin ทำได้ และต้องระบุเหตุผล

**ความปลอดภัย:** รหัสผ่านเก็บด้วย `password_hash()`, ทุกคำสั่ง SQL ใช้ Prepared Statement (PDO),
ทุกฟอร์มมี CSRF token, ทุกหน้าตรวจ session และสิทธิ์ผู้ใช้, ราคาขายดึงจากฐานข้อมูลเสมอ (ไม่เชื่อค่าจากหน้าเว็บ)

## โครงสร้างไฟล์

```
bangpe/
├── config/database.php      ตั้งค่าฐานข้อมูลและระบบ
├── includes/                ฟังก์ชันกลาง, ส่วนหัว/ท้ายของทุกหน้า
├── api/                     checkout (บันทึกการขาย), notifications (แจ้งเตือน)
├── assets/style.css         สีและหน้าตาของระบบ
├── database.sql             โครงสร้างตาราง + ข้อมูลตัวอย่าง
└── *.php                    หน้าต่าง ๆ ของระบบ
```

## ก่อนใช้งานจริง

- เมนู วัตถุดิบ สูตร และผู้จำหน่ายในไฟล์ `database.sql` เป็นข้อมูลตัวอย่าง ควรแทนด้วยข้อมูลจริงจากร้าน
- ปริมาณในสูตรควรชั่งตวงจริงจากครัว ยอดสต็อกจะแม่นแค่ไหนขึ้นกับสูตร
- ควรนับสต็อกจริงเป็นระยะ (เช่น ทุกสัปดาห์) แล้วบันทึกที่หน้า "นับสต็อก"

## ยอดขายรายสัปดาห์

- หน้าหลักแสดงยอดขายวันนี้เป็นแถบใหญ่ (กราฟรายชั่วโมงเทียบเมื่อวาน ณ เวลาเดียวกัน) และยอดขายสัปดาห์นี้เป็นการ์ดเล็กด้านล่าง
- การเทียบใช้ "ช่วงวันเดียวกัน" เช่น วันนี้วันพุธ จะเทียบยอด จันทร์–พุธ ของสัปดาห์ก่อน เพราะสัปดาห์นี้ยังไม่ครบ 7 วัน ถ้าเทียบทั้งสัปดาห์จะดูเหมือนยอดตกทุกครั้ง
- รายงาน > ยอดขายรายสัปดาห์ แสดงย้อนหลัง 8 สัปดาห์ (เลือกช่วงวันที่เองได้) พร้อมยอดเปลี่ยนแปลงจากสัปดาห์ก่อนและเมนูขายดีของแต่ละสัปดาห์
- ฟังก์ชันที่ใช้อยู่ใน `includes/functions.php`: `week_start()`, `week_daily_sales()`, `thai_week_range()`

## หน้าสรุปยอดขาย (`sales_summary.php`)

กดการ์ดยอดขายวันนี้/สัปดาห์นี้/เดือนนี้ในหน้าหลัก จะเข้ามาหน้านี้ เปิดได้ทั้งผู้ดูแลและแคชเชียร์ แสดงยอดรวม จำนวนบิล จำนวนจาน เฉลี่ยต่อบิล รายการอาหารที่ขายได้เรียงจากมากไปน้อย และรายการบิลพร้อมอาหารในแต่ละบิล (กดเลขบิลเพื่อดูรายละเอียดหรือพิมพ์ใบเสร็จซ้ำ)

## ความช่วยเหลือในระบบ

- ทุกหน้ามีกล่อง "วิธีใช้" สีเหลืองด้านบน บอกว่าหน้านั้นใช้ทำอะไรและมีขั้นตอนอะไรบ้าง กด "เข้าใจแล้ว ซ่อน" เบราว์เซอร์จะจำไว้แยกแต่ละหน้า และกดปุ่ม "วิธีใช้" มุมขวาบนเพื่อเปิดอีกครั้ง
- แก้ข้อความคำแนะนำได้ที่ `includes/help.php` ไฟล์เดียว
- หน้าหลักมีปุ่มทางลัด 4 ปุ่มตามสิทธิ์ ผู้ดูแลได้ ขาย/รับของเข้า/ของเสีย/นับสต็อก ส่วนแคชเชียร์ได้ ขาย/บิลขาย/สรุปที่ขาย/วัตถุดิบคงเหลือ
